# Faster version of do.call

Faster version of do.call

## Usage

``` r
do_call(what, args, quote = FALSE, envir = parent.frame())
```

## Source

Gmisc

## Arguments

- what:

  The function to call

- args:

  The arguments to pass to the function

- quote:

  Whether to quote the arguments

- envir:

  The environment to look for the function in the parent frame

## Value

The same results as using do.call()
