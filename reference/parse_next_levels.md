# Parse all next levels of current cell name

Parse all next levels of current cell name

## Usage

``` r
parse_next_levels(
  cell_name,
  level,
  max_level,
  nl_marks,
  cell_markers,
  next_imm_levels
)
```

## Arguments

- cell_name:

  The current cell name

- level:

  The current level

- max_level:

  The max level

- nl_marks:

  The next level marks

- cell_markers:

  The cell markers data frame

- next_imm_levels:

  The next immediate levels

## Value

A list of all possible cell names
