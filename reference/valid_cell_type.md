# Get the valid cell type for a given cell type

Get the valid cell type for a given cell type

## Usage

``` r
valid_cell_type(cell_type, gs)
```

## Arguments

- cell_type:

  A vector cell types, with length the same as the number of cell type
  levels

- gs:

  A list of cell names for each cell type level

## Value

A string of valid cell types or NULL if the cell type is invalid
